Thread Radar 0.1.19.1

Firefox (Android) bir siteden gelen eklentiyi tıklamayla kurmaz, dosyadan kurar:

1. Dosyayı indir

  1. Firefox ⋮ → Ayarlar → en altta Firefox hakkında → Firefox logosuna 5 kez dokun ("hata ayıklama menüsü etkinleştirildi").
  2. Geri dön: Ayarlar'da Dosyadan eklenti yükle çıkar. Dokun → İndirilenler → thread-radar-0.1.19.1.xpi → Ekle.
  3. Uygulama kendi sekmesinde açılır. Sonra: Firefox ⋮ → Uzantılar → Thread Radar.

Bir kez kurulunca güncellemeleri Firefox kendisi indirir.
